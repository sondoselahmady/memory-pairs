# Memory Pairs

A browser-based memory matching game built with HTML, CSS, and JavaScript.

## Play

Open `index.html` in a web browser. Choose a theme by starting a new game, then flip cards to find matching pairs.

## Features

- Four themes: Animals, Food, Sports, and Halloween
- Randomized card order
- Flip counter and score
- New Game button
- Responsive card board styling

## Files

- `index.html` — page structure
- `style.css` — layout and styling
- `game.js` — card matching and score logic
- `main.js` — themes and browser UI behavior
